## 왜 필요한가

2026년 발사와 바다에 관한 규정이 새로 생겼습니다.

- **우주개발 진흥법 개정** (2027.02 시행): 발사안전구역을 **필요 최소 범위**로 지정하고, 구역 안 해상구조물은 사전 협의
- **나로우주센터 민간 활용 가이드라인** (2026.06): 민간 발사기업이 **어업 피해 보상** 책임 부담

의무는 생겼지만, 발사가 어업에 주는 영향을 발사 전에 비교할 공통 자료는 부족합니다. → [자세히 보기](docs/PROPOSAL.md#2-기획력-planning--design)

## 이미 확인한 것

나로우주센터 남쪽 가정 통제구역(24×78km)을 Global Fishing Watch 위성 AIS로 분석했습니다.

- 연 **12~14만 시간**의 조업, 연 **860~960척** (4년간 1,568척 중 1,550척 한국 선적, 트롤·고정자망 등 연안·근해 어업)
- 4년 모두 **2월·7월 조업이 가장 적음** → 후보일·구역 대안에 따라 예상 영향이 12~76시간, **최대 약 84% 차이** (통제 4시간 가정)
- 과거 누리호 발사일은 일 단위 자료로는 영향이 뚜렷하지 않음 → 손실 "산정"이 아니라 영향 "비교와 근거"에 집중하고, 시간 단위 인과추론으로 재검증 예정

## 핵심 기능

| 모듈 | 하는 일 | 핵심 기술 |
|---|---|---|
| 0. 해역 데이터 엔진 | 해역 격자별·월별 조업 밀도와 정기 조업 선박 | Global Fishing Watch 위성 AIS (+SAR 표본 보정) |
| 1. 후보 비교 | 발사운영팀이 준 후보일 × 통제구역 대안별 예상 영향 순위 | 과거 같은 시기 기준선, 통제 시간 환산 |
| 2. 영향근거 리포트 | 영향 어선·조업기회·어구 구성·데이터 한계를 담은 협의용 리포트 | 리포트 자동 생성 (.md / .csv) |

오션클리어는 **안전구역을 설계·인증하지 않고, 발사일과 보상액을 결정하지 않습니다.** 안전성이 확인된 대안들 사이에서 어업영향을 비교합니다.

## 기술 고도화 (제출 전 개발)

| 축 | 해결하는 한계 | 방법 |
|---|---|---|
| ① 발사 영향 인과추론 | 일 단위로는 통제 효과를 측정 못 함 | 누리호 발사 4건의 시간 단위 위성 기록 + 합성 통제·이벤트 스터디, 선박별 대체 조업 추적 |
| ② 기상 반영 확률 예측 | 기준선은 날씨를 모름 | ERA5 바람·파고 + LightGBM 분위수 회귀, 연도별 백테스트 |
| ③ SAR 포착률 보정 | AIS 미탑재 선박 누락 | Sentinel-1 SAR 탐지와 AIS 교차 매칭 (심화: CFAR 직접 탐지) |

## 데모 실행

```bash
git clone <저장소 주소>
cd oceanclear
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```

화면: ① 해역 조업 지도 ② 후보일 비교 ③ 영향근거 리포트 ④ 과거 발사일 확인

데이터는 GFW 지도에서 내려받은 CSV를 `data/<연도>/`에 넣어 사용합니다 ([개발 계획 4장](docs/DEV_PLAN.md#4-데이터)).
