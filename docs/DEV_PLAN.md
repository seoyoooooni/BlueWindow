## 1. 개발 목표와 범위

**목표:** 나로우주센터 앞바다를 대상으로, 발사운영팀이 준 **실행 가능한 후보일과 안전 통제구역 대안**의 어업영향을 위성 데이터로 비교하고, 그 근거를 협의용 리포트로 만든다.

**설계 원칙**

- 안전구역을 설계·인증하지 않는다. 통제구역은 발사기업·발사장이 준 입력값이다.
- 발사일을 결정하지 않는다. 주어진 후보들의 해양영향 순서만 제공한다.
- 보상액을 결정하지 않는다. 영향 규모와 근거, 2단계에서 참고 범위만 제시한다.
- 모든 결과에 불확실성 범위와 데이터 한계를 함께 표시한다.
- 새 모델은 **기존 기준선보다 나을 때만** 교체한다.

| 구성 요소 | 내용 | 상태 |
|---|---|:---:|
| 해역 데이터 엔진 | GFW 격자·선박·일별 자료 적재, 조업 밀도 | ✅ 완료 |
| 후보 비교 | 과거 같은 시기 기준선, 통제 시간 환산, 후보×구역 순위 | ✅ 완료 |
| 영향근거 리포트 | 수치·어구·선박·한계, .md/.csv 내려받기 | ✅ 완료 |
| 과거 발사일 확인 (일 단위) | 누리호 2·3·4차 | ✅ 완료 |
| **① 시간 단위 인과추론** | 합성 통제, 이벤트 스터디, 선박별 대체 조업 | 계획 (2주차) |
| **② 기상 반영 확률 예측** | ERA5 + LightGBM 분위수 회귀, 백테스트 | 계획 (3주차) |
| **③ SAR 포착률 보정** | GFW SAR 매칭/비매칭, (심화) Sentinel-1 직접 탐지 | 계획 (4주차) |
| 금액 환산 | 위판·생산 통계로 시간당 어업가치 | 계획 (4주차) |
| 배포 | Streamlit Community Cloud | 계획 (4주차) |

**제외:** 낙하물 궤적·몬테카를로 모델(발사체 제원 비공개, 공식 안전구역 계산으로 오해될 위험), 모바일 앱, 최종 보상금 계산.

## 2. 시스템 구조

```
[수집]  GFW 지도 CSV (현재)  →  GFW API: 4Wings HOURLY · Events · SAR · Vessels (1주차)
        ERA5 바람·파고 (3주차) · 위판/생산 통계 (4주차) · 항행경보 통제구역 좌표 (1주차)
            ↓  ingest/  (캐시: data/raw → data/processed/*.parquet)
[정제]  선박 식별 통일(MMSI), 비어선 분류 점검, 격자 통일(0.1°/0.01°)
            ↓
[분석]  core.py 기준선 ─┬─ ① causal/  합성 통제 · 이벤트 스터디 · 대체 조업
                        ├─ ② forecast/ 분위수 예측 · 백테스트
                        └─ ③ sar/      포착률 추정 · 보정 (심화: CFAR 탐지)
            ↓
[화면]  app/streamlit_app.py  ① 지도 ② 후보 비교 ③ 리포트 ④ 발사 영향 검증
```

- 무거운 계산(모델 학습, API 수집, SAR 처리)은 미리 실행해 결과를 저장하고, 화면은 저장된 결과만 읽는다.
- 계산 로직과 화면을 분리해, 로직은 따로 테스트하고 운영 시 API로 감쌀 수 있게 한다.

## 5. 현재 구현: 기준선과 후보 비교

구현 파일: `app/core.py`

| 단계 | 계산 |
|---|---|
| 1. 구역 | 격자 중심이 통제구역 대안 안에 있는 칸만 포함 |
| 2. 일별 집계 | 날짜별 조업시간·선박 수. **조업 없는 날은 0으로 채움** |
| 3. 기준선 | 후보일과 같은 시기(연중 ±15일)의 과거 모든 해 일별 값 → 중앙값, 75백분위 |
| 4. 통제 시간 환산 | 조업기회 = 하루 조업시간 × (통제 시간 ÷ 24) |
| 5. 정기 조업 선박 | 같은 시기에 2개 연도 이상 이 구역에서 조업한 배 |
| 6. 순위 | 후보일 × 구역 대안을 조업기회 중앙값 순으로 정렬 |

**현재 결과 (2022~2025, 통제 4시간, 조업기회 중앙값)**

| 후보일 | 구역 A (기본) | 구역 B (연안 제외) | 구역 C (남쪽 축소) |
|---|---:|---:|---:|
| 2027-02-10 | 21시간 | **12시간** | 21시간 |
| 2027-05-12 | 63시간 | 45시간 | 55시간 |
| 2027-09-15 | 76시간 | 63시간 | 70시간 |

→ 가장 작은 조합(2월·B)은 가장 큰 조합(9월·A)보다 **약 84% 작다.**

**한계:** 날씨를 모른다(→ ②), 통제 효과를 직접 측정하지 않는다(→ ①), AIS 미탑재 선박이 빠진다(→ ③), 하루 중 조업이 균등하다고 가정한다(→ ① 시간대 분포로 대체).

## 6. 기술 축 ①: 시간 단위 발사 영향 인과추론

**질문:** 발사 통제 시간 동안 통제구역 조업이 실제로 얼마나 줄었고, 그 조업은 어디로 갔는가?

**왜 필요한가:** 일 단위 분석에서는 효과가 보이지 않았다(3차만 낮은 편, 2차는 오히려 높음). 몇 시간짜리 통제가 하루 합계에 묻히기 때문이다. 시간 단위로 보면 측정할 수 있다.

### 6-1. 데이터

- 대상 발사: 누리호 1차(2021-10-21), 2차(2022-06-21), 3차(2023-05-25), 4차(2025-11-27 KST) — 4건
- 발사별 전후 4주, **시간 단위** 격자 조업(4Wings HOURLY)
- 처리군: 통제구역 격자 / 인접군: 통제구역 바로 바깥 고리 / 후보군(donor pool): 멀리 떨어진 남해 연안 격자 20~40개
- 통제 시작·종료 시각: 항행경보·보도자료

### 6-2. 방법

| 방법 | 내용 |
|---|---|
| 합성 통제 (Synthetic Control) | 발사 전 기간의 통제구역 시간별 조업을, 후보군 격자들의 가중합(가중치 ≥ 0, 합 1)으로 가장 잘 재현하도록 가중치를 구함 → 통제 시간대의 "발사가 없었다면" 조업 추정 → 실제와의 차이 = 효과 |
| 플라시보 검정 | (시간) 발사 없는 날에 같은 절차를 반복해 효과 분포를 만들고, 실제 효과가 그 분포에서 얼마나 극단인지로 p값 계산 / (공간) 후보군 격자를 가짜 처리군으로 바꿔 반복 |
| 이벤트 스터디 회귀 | 조업시간(격자 c, 시각 t) = 격자 고정효과 + 요일×시각 고정효과 + Σ_k β_k·[발사 기준 k시간째 × 처리군] + γ_k·[k시간째 × 인접군] + 오차 → β는 통제구역 효과, γ는 **인접 해역으로 밀려난 조업(대체)** |
| 선박별 대체 조업 | 발사 전 2주간 통제구역에서 조업한 배를 추적(Events API): 발사 당일 ① 구역 밖 인근에서 조업 ② 다른 시간에 조업 ③ 조업 안 함 → **대체율** |

### 6-3. 산출물

- 통제 시간대 조업 감소율 (95% 신뢰구간, 플라시보 p값)
- 인접 해역 증가분과 선박 대체율
- 하루 중 시간대별 조업 분포 → 5장의 "균등 분포" 가정 교체
- 화면 ④를 시간 단위 결과로 교체

### 6-4. 주의

- 발사가 4건뿐이라 표본이 작다 → 발사별 결과와 합친 결과를 모두 제시, 플라시보로 우연 가능성 평가
- 인접 해역을 단순 비교군으로 쓰면 대체 조업 때문에 효과가 부풀려진다 → 인접군을 따로 추정(γ)하고 먼 해역을 비교군으로 쓴다
- 효과가 통계적으로 뚜렷하지 않으면 그대로 보고한다 (그 자체가 "노출 규모 중심" 설계의 근거)

## 7. 기술 축 ②: 기상 반영 확률 예측 모델

**질문:** 특정 후보일에 통제구역 조업이 어느 범위일지, 날씨까지 고려해 예측할 수 있는가?

**왜 필요한가:** 하루 조업은 0~1,300시간 이상으로 흔들리고, 기준선은 그 이유(주로 날씨)를 모른다.

### 7-1. 설계

| 항목 | 내용 |
|---|---|
| 예측 대상 | 통제구역 일별 조업시간 (확장: 격자별) |
| 모델 | LightGBM 분위수 회귀 (10·50·90 백분위) + 필요 시 등각 예측(conformal)으로 구간 보정 |
| 특징 | 연중 날짜(sin/cos), 월, 설·추석 등 명절 전후, 10m 풍속·유의파고(ERA5, 일 최대·평균), 작년 같은 시기 조업, 최근 조업(예측 시점 기준 과거만) |
| 두 가지 모드 | **장기(1~3개월 전):** 기상 대신 평년 기후값 / **단기(7일 전):** 예보 기상 (학습·검증은 ERA5 실측으로 대체해 상한 성능 측정) |

### 7-2. 검증

| 구분 | 내용 |
|---|---|
| 분할 | 연도 단위 롤링: 2022~23 학습 → 2024 시험, 2022~24 학습 → 2025 시험 |
| 지표 | 분위수 손실(pinball loss), 80% 구간 실제 포함률, **후보 순위 스피어만 상관** |
| 순위 시뮬레이션 | 시험 연도에서 ±30일 안의 후보 3~5개를 무작위로 여러 번 뽑아, 예측 순위와 실제 순위의 일치도를 기준선과 비교 |
| 채택 기준 | 순위 상관과 분위수 손실 모두 기준선보다 좋을 때만 화면에 적용 |
| 설명 | 특징 중요도, 후보일별 주요 요인(예: "파고 3m 예보로 조업 감소 예상") |

### 7-3. 산출물

- 기준선 대비 성능표
- 후보 비교 화면에 "장기 / 7일 전" 모드 추가, 예측 구간 표시

## 8. 기술 축 ③: SAR 기반 AIS 포착률 보정

**질문:** AIS에 안 잡히는 배가 얼마나 되고, 그만큼 영향이 과소 추정되는가?

### 8-1. 기본 (GFW SAR)

- 통제구역·주변의 Sentinel-1 촬영 장면별 SAR 선박 탐지를 받아 **AIS 매칭 / 비매칭** 수를 센다
- 포착률 = 매칭 ÷ (매칭 + 비매칭), 해안 거리·계절별로 추정, 장면 단위 부트스트랩으로 신뢰구간
- 보정 노출 = 조업기회 ÷ 포착률 (보정 전후 함께 표시)
- 한계: Sentinel-1은 소형 선박(대략 15m 미만) 탐지가 약하고 촬영 시점에만 존재 → 보정값은 **하한**이며, 연속 항적을 대신하지 않는다

### 8-2. 심화 (시간 여유 시): Sentinel-1 원본 직접 탐지

| 단계 | 내용 |
|---|---|
| 1 | Copernicus Data Space에서 나로 해역 Sentinel-1 IW GRD 장면 검색·다운로드 |
| 2 | 방사 보정(σ0), 해안선 기반 육지 마스킹 |
| 3 | CA-CFAR(주변 배경 대비 밝은 점 탐지)로 선박 후보 추출, 연결 성분으로 묶기, 크기 필터 |
| 4 | GFW SAR 탐지와 위치 매칭해 정밀도·재현율 계산 → 자체 탐지 성능 검증 |
| 5 | 같은 시각 AIS와 매칭해 비매칭 선박(dark vessel) 추출 |

## 9. 영향 금액 환산

- 자료: KOSIS 어업생산동향(지역·월별 생산량·금액), 수협 위판 통계
- 시간당 어업가치 ≈ 해당 해역·월 생산금액 ÷ 같은 기간 조업시간 (범위로 제시)
- 결과: "발사 1회 통제 시 영향 어업가치 약 ○~○만 원, 후보 선택으로 ○만 원 차이"
- **보상액이 아닌 참고 규모**로 표시. 대체 조업(①)을 반영한 순영향 범위도 함께 제시
